# retrieval-quiz-builder

## 目的

學習者是伺服器業務，目標 **Pre-sales／SE**，**每天只有 1 小時**。每天早上閉卷做 6 題，週六做 12 題（25 分鐘），模組末做 60 分鐘的模組考；這些測驗是整個讀書計畫的主引擎（提取練習、間隔、交錯、校準）。這個 skill 的工作是**照配方組卷**：從已經寫好的 K 點裡挑題、依題型規則改寫成題目、附上有 `file:line` 的解答。你不需要懂整個領域，只需要忠實轉述 K 點並遵守題型規則；K 點本身已經是帶數字與口徑的可檢驗陳述。

## 輸入

| 使用者說法                                   | 類型      | 參數                 |
| -------------------------------------------- | --------- | -------------------- |
| 「出 2026-11-24 的每日測驗」「出 W02D02 的題」 | daily     | 日期或 WwwDdd        |
| 「出第 2 週的週前測」                          | pretest   | 週次（模組首週才有）  |
| 「出第 2 週週測」                              | weekly    | 週次                 |
| 「出模組一的模組考」                           | module    | 模組 1～4            |
| 「依錯題本出模組一重考卷」                     | retake    | 模組                 |
| 「出模組二的模擬面試題庫（TAM 場）」           | interview | 模組 + 主場職缺      |

日期與 WwwDdd 互轉、以及間隔抽題的來源日，交給腳本：

```bash
python3 .claude/skills/retrieval-quiz-builder/scripts/build_schedule.py --date 2026-11-24 --type daily
```

它會輸出：目標週日代碼、每個題序該抽的來源日（D-1／D-3／D-7／D-14+）、各來源日可用的 K 點編號與檔案、錯題本中到期的題。腳本找不到某來源日的 K 點時會標 `missing`，這時用 `course-handout-builder/references/weekly-day-plan.md` 的來源文章現場建 K 點（標「暫定」）再出題，不要跳過那個題序。

## 流程

1. **讀配方**：`00_study_plan/02_assessment_spec.md` 第 3 節（題型與禁忌）、第 4 節（各類型配方；**第 4 節開頭的「1 小時・Pre-sales 版」優先**）、第 6 節（解答格式）。配方是固定的，不要自行調整題數或比例；若學習者要求調整，照辦並在測驗標頭註明。
2. **跑腳本取得抽題來源**（上面的命令）。
3. **挑 K 點**：每個題序從對應來源日的 K 點中挑一條。優先順序：錯題本到期 > 上次低信心或答錯 > 難度與題型匹配 > 尚未出過題的 K 點。同一份測驗不重複同一 K 點；同一 K 點在連續兩天不用同一題型。
4. **寫題**：規則與範例在 `references/item-writing-guide.md`。核心四條：不出選擇題；題幹不洩漏答案；每題只考一個 K 點；涉及數字的題，答案必須含口徑。每日最後一題固定是口說（OR），受眾依星期輪替（一 客戶 CxO／採購、二 客戶工程師、三 自家業務、四 客戶反對意見、五 面試官）。情境優先用售前場景：客戶需求 → 配置 → 理由。
5. **寫解答**：每題包含 K 點編號、題型、參考答案（含口徑）、來源 `file:line`、常見錯因；每份測驗至少一個「精緻化提問」。解答檔與題目檔分開，題目檔不含答案。
6. **輸出**：路徑與命名見下表；更新該週 `quizzes/weekNN/README.md` 的清單（不存在就依第 1 週的格式建立）。
7. **驗證**：

```bash
python3 .claude/skills/retrieval-quiz-builder/scripts/check_quiz.py 00_study_plan/quizzes/week02/d02_quiz.md --key 00_study_plan/quizzes/week02/answer_key.md
```

修到沒有 `ERROR`。

## 輸出路徑

| 類型      | 題目檔                                           | 解答                                     |
| --------- | ------------------------------------------------ | ---------------------------------------- |
| pretest   | `00_study_plan/quizzes/weekNN/d01_pretest.md`     | `weekNN/answer_key.md`（追加區段）        |
| daily     | `weekNN/dMM_quiz.md`（MM = 02～05；模組首週 D1 為前測，其他週 D1 也是 daily） | 同上                      |
| weekly    | `weekNN/d06_weekly_quiz.md`                       | 同上                                     |
| module    | `quizzes/moduleN_exam.md`                         | `quizzes/moduleN_exam_key.md`            |
| retake    | `quizzes/moduleN_retake.md`                       | `quizzes/moduleN_retake_key.md`          |
| interview | `quizzes/interview_bank_moduleN.md`               | 題庫本身含「好答案要素」                  |

格式以第 1 週的檔案為範本：`00_study_plan/quizzes/week01/`（題目表欄位：#、題型、來源、題目、我的答案、信心）。

## 各類型的特別規則

- **pretest**：涵蓋整週五天的 K 點各 2 題，不計分；題目可以比每日測驗難，目的是「先失敗再學」。只在模組首週（W1、W4、W8、W11）出。
- **weekly**（1 小時版 12 題）：本週 6（FR 1、SA 1、CA 2、TJ 2）+ 前幾週 3（MT 1、SA 1、TJ 1）+ 遷移 1 + 客戶信 1 + 口說 1（3 分鐘，對客戶工程師）。遷移題是唯一允許「K 點清單外」的題：給一個講義沒出現的新情境，要求用本週 K 點的機制解釋；解答仍要指回 K 點。客戶信題給 100 字情境（最好是客戶詢價或比價），評分要素寫在解答。
- **module**（1 小時版 60 分鐘）：筆試 20 題 + 1 題 200 字客戶情境長答 + 1 白板題；本模組 14 題、前模組 6 題；白板題抽難度 3～4 的 K 點。
- **retake**：只從錯題本與同 K 點出；題幹與原題不得相同（換情境、換數字方向、換受眾）；題數同模組考。
- **interview**：格式照 `quizzes/interview_bank_module1.md`：英文提問、中文「好答案要素」、追問；A 技術深度 8 題共用，B 職能情境以 Pre-sales 為主（4～5 題：需求訪談、sizing、競品應對、TCO），其他職缺各 1 題，C 動機 3 題。

## 便宜模型最常犯的錯

| 錯                                   | 改法                                                               |
| ------------------------------------ | ------------------------------------------------------------------ |
| 出選擇題                             | 改 TJ（判斷並說理）或 SA                                           |
| 題幹把數字寫出來再問「對不對」       | 問「是多少、什麼口徑、怎麼算」                                     |
| 解答沒有 `file:line`                 | 回 K 點清單抄；K 點沒有就不出這題                                  |
| 自己補一個 K 點沒有的「事實」        | 不行；遷移題除外，且遷移題解答要指回 K 點                          |
| 每日 6 題全部來自昨天                | 第 3～5 題必須是間隔抽題；腳本會給來源日                           |
| 忘了口說題或口說題沒指定受眾         | 第 6 題固定 OR，受眾依星期輪替（Pre-sales 版）                      |
| 用簡體                               | 題目與解答繁體；引用原文可簡體加引號                               |
