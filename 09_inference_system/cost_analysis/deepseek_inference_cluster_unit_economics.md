# 155 萬億 tokens/天，單卡運營利潤率 93%：token 生意可以做成暴利

> DeepSeek 官方披露的運營數字，加上一組保守成本假設：單卡年收入 33 萬美元，成本只占 3–7%。這套賬本只屬於長上下文、高快取命中、滿載運營的玩家。

按官方資料，一張卡一年收入 33 萬美元；按 2 年折舊，單卡運營利潤率 93%，按 4 年折舊是 96%。**token 生意可以做成暴利。**

這些數字都有出處：155 萬億 tokens/天、96% 快取命中、38 美元/卡時都是 DeepSeek 官方披露的生產參數；這篇文章把它們拆成可復算的單卡賬本，並標出哪些是官方資料、哪些是成本假設。

前提是 77K 長輸入、96% 命中、P:D 1:1、滿載運營。DeepSeek 的推理架構會按負載調整 P/D 配比、快取和排程，換一種負載不能直接套用。

## 一、官方披露的生產參數

DeepSeek 這次給了一張“實際線上執行資料”表。核心參數如下：

| 階段    | 指標                       | 線上實測                    |
| ------- | -------------------------- | --------------------------- |
| prefill | 每卡吞吐（不含快取命中）   | 60K tps                     |
| prefill | 每卡吞吐（含快取命中）     | 1.5M tps                    |
| prefill | 平均輸入快取命中率         | 96%                         |
| prefill | 首字時延（TTFT）平均 / P99 | 400ms / 1000ms              |
| prefill | 平均輸入長度               | 77K tokens                  |
| decode  | 每卡吞吐                   | 14K tps                     |
| decode  | 吐字速度（每使用者）         | 230 tps（程式碼場景 300 tps） |
| kvcache | 不活躍後儲存時間           | 72 小時                     |
| 部署    | P:D 比例                   | 接近 1:1                    |
| 收入    | 平均每卡每小時             | 38 美元（按谷價）           |

![DeepSeek 官方披露的線上執行資料（2026-10-09 資料）](assets/deepseek-production-data-20261009.jpg)

官方對 38 美元的口徑是：按谷價、不考慮波峰波谷的平均每卡收入。

38 美元是結果。三個配套數字說明它是怎麼來的。

96% 的輸入快取命中率讓 prefill 處理的 token 絕大多數直接從快取讀取，不需要重新計算。77K 的平均輸入長度對應長上下文、多輪工具呼叫的 agent 類負載；P:D 接近 1:1，prefill 和 decode 各占一半卡，系統按“長輸入、短輸出”的負載配比。

官方同時註明了“機器已經預留了一定冗餘，以應對流量的波動”。這會影響後面的卡數折算。

另外，14K tps 的 decode 吞吐、230 tps 的單使用者吐字速度，可以反推出每張 decode 卡約服務 61 路併發（14K ÷ 230 ≈ 60.9，保守取整常記作 50–60 路；程式碼場景 14K ÷ 300 ≈ 47 路）。這是一個推導值，不是官方直接給出的指標。

這套服務背後的推理框架是 DeepInfer。DeepSeek 用它支撐 V4.1 Flash 的高吞吐、低延遲推理；2026-10-20，官方公眾號宣佈將 DeepInfer 開源（Apache 2.0），同步開源 deepseek-recipe 編解碼元件（MIT）。

DeepInfer 支持分布式推理、推測解碼、SWA Bounded Replay、結構化輸出，兼容 NVIDIA 與華為昇騰。生產參數本身來自官方知乎技術報告。

## 二、155 萬億 tokens/天，摺合多少張卡

官方文章稱，單一叢集每天處理 155 萬億 tokens。這個總量和每卡吞吐可以互相校驗。

按一對卡（1 張 prefill + 1 張 decode）計算：

- prefill：1.5M tps × 86,400 秒 ≈ 1,296 億 tokens/天（含快取命中）
- decode：14K tps × 86,400 秒 ≈ 12.1 億 tokens/天
- 合計：約 1,308 億 tokens/對·天

用 155 萬億除以 1,308 億：

```text
155 × 10^12 ÷ (1.308 × 10^11) ≈ 1,185 對 ≈ 2,370 張卡
```

2,370 是按滿負載吞吐折算出的有效卡數，不是實際部署的物理卡數。官方說機器預留了冗餘，實際部署只會更多，不會更少。把它當成“這套系統等效需要多少張卡在滿負荷工作”更準確。

按每卡每小時 38 美元、全年 8,760 小時粗算：

```text
2,370 張 × $38 × 8,760 h ≈ $7.9 億/年
```

它按“有效卡數”和官方“平均每卡收入”折算，不是審計過的叢集營收；官方說機器預留了冗餘，實際部署卡數可能更多，所以這個數字只作規模參考，單卡賬本仍以 38 美元/卡時為準。

另一個交叉校驗是隱含實收單價：

```text
$76/對·小時 ÷ 5,450M tokens/對·小時 ≈ $0.0139/M tokens
```

這是被快取命中與谷價折扣稀釋後的全口徑實收價，不是牌價。

## 三、單卡賬本：33 萬美元收入，成本多少

收入端按官方口徑：

```text
$38/卡時 × 8,760 小時 = $332,880/卡·年
```

成本端需要一組假設。這裡用一套偏保守的全棧 capex 估算：整卡、伺服器、網路、機房加起來，按 GPU 採購價的 1.5–2 倍計，折合 3–4 萬美元/卡；電力按谷價；不考慮銷售、研发、管理等公司級費用。折舊分兩種口徑：

| 折舊口徑                       |  年成本/卡 |   單卡年利潤 | 單卡利潤率 |
| ------------------------------ | ---------: | -----------: | ---------: |
| 4 年直線（正常會計）           | 約 $10–13k | 約 $320–323k |     約 96% |
| 2 年（按更快的迭代節奏）       | 約 $17–23k | 約 $310–316k |     約 93% |

成本折到每卡小時是：

- 4 年折舊：約 $1.1–1.5/卡時，只相當於 38 美元實收的 3–4%；
- 2 年折舊：約 $1.9–2.6/卡時，相當於實收的 5–7%。

無論按哪種折舊，成本都只佔實收的個位數百分比；實收約為成本的 15–35 倍。即使收入跌到每小時 3 美元，折舊和電費仍然能覆蓋。這個成本比例的分母是實收，不是牌價產值。

把折舊壓到 1 年、只算 capex，成本約 $3.4–4.6/卡時，單卡利潤率仍約 88–91%；加上電費會略低，結論不變。

93–96% 是單卡層面的運營利潤率，只扣了折舊和電費，不含銷售、研发、管理等費用，也不是公司淨利潤。官方給的 38 美元是收入，不是利潤。

## 四、槓桿在哪裡：prefill 卡與 96% 快取命中

prefill 卡的名義產值更高，decode 卡更像高 SLA 支撐層；差距約 1.6 倍，不是數量級差異。

按 DeepSeek 官方英文價格頁的 USD 谷價（2026-10-20 查詢）：`deepseek-flash` / V4.1-Flash-1017 的 cache hit $0.003/M、cache miss $0.15/M、output $0.60/M；高峰時段價格翻倍。官方 38 美元/卡時也按谷價，口徑一致。

|                   |                    Prefill 卡 |                 Decode 卡 |
| ----------------- | ----------------------------: | ------------------------: |
| 每小時處理 tokens |       54 億（96% 為快取命中） |                  0.504 億 |
| 牌價產值/卡時     | 5,400M × $0.00888/M ≈ $48 | 50.4M × $0.60/M ≈ $30 |

prefill 卡的每小時牌價產值約為 decode 卡的 1.6 倍。差距來自兩件事：

1. 96% 快取命中把 prefill 的等效吞吐放大了 25 倍（1.5M / 60K）；
2. 命中單價是未命中的 1/50（$0.003 vs $0.15），但 prefill 處理量足夠大，名義產值仍然更高。

72 小時 KV cache 的價值主要在吞吐，不在單價：它把快取讀取變成可計價的 token 處理量，降低 prefill 單位成本。命中單價只有未命中的 1/50，產值槓桿沒有 25 倍的吞吐放大那麼誇張。

$48 和 $30 是牌價產值，不是實際收入。兩張卡的平均牌價產值是 $39.1/卡時，官方實收是 $38/卡時，實現率約 97%。差距只有約 3%，更可能來自取整、流量結構和口徑，而不是大幅折扣。官方 38 美元與按當前谷價和 96% 命中算出的平均 token 收入基本一致；暴利來自成本低，而不是“高牌價、低實收”的折扣差。

## 五、價格與折舊：兩個敏感性變數

這套賬本對應 77K 輸入、96% 快取命中、P:D 1:1 的當前負載。DeepSeek 的推理架構會按負載調整 P/D 配比、快取和排程，其他負載下的單卡數字不能直接套用；這是當前 agent 負載口徑下的單卡模型，不是通用推理利潤率。敏感性只做兩項：牌價和折舊。

先看牌價。收入以 token 牌價計價，成本主要是鎖死的折舊和電費。假設用量不變、牌價減半，單卡收入減半，折舊不變；按 2 年折舊口徑，利潤率會從 93% 降到 86% 左右。牌價繼續下行，壓力會逐步顯現。現實中價格下降可能帶來用量增長，結果取決於需求彈性，不能只看單價。

折舊年限是最不敏感的變數。按 1 年折舊、只算 capex，單卡利潤率仍有 88–91%；按 4 年折舊則是 96%。只要負載和價格不崩，折舊年限決定賺多少，不決定是否賺錢。

| 變數 | 變化             | 對單卡賬本的影響                        |
| ---- | ---------------- | --------------------------------------- |
| 牌價 | 減半（用量不變） | 收入減半，利潤率約降到 86%              |
| 折舊 | 4 年 → 1 年      | 成本升到 $3.4–4.6/卡時，利潤率仍 88–91% |

## 六、行業影響

推理不是一門同質化生意。同樣是賣 token，輸入長度、快取命中率、併發密度不同，運營者會按自己的負載調整架構，單卡產出也會不同。DeepSeek 這組資料描述的是一種把長上下文、快取和 P:D 配比做到極致的運營形態。

同樣的 GPU，在不同運營者手裡是不同的資產。高負載、高快取命中的叢集，單卡能產生穩定現金流；低利用率、短上下文的叢集，同一張卡可能連折舊都覆蓋不了。對 GPU 租賃、融資和資產處置來說，抵押品的價值不只取決於卡的價格，還取決於運營者的負載品質。

價格戰能打到多低，由工程效率最高的玩家決定。頭部玩家的單卡成本只佔實收的個位數百分比，有空間主動降價；效率較低的玩家，降價空間小得多，價格壓到頭部水平，可能連折舊和電費都覆蓋不了。這解釋了為什麼同樣做推理服務，有的廠商能打價格戰，有的不能。

據 21 世紀經濟報道 2026-08-28 的報道，截至 2026 年 6 月，我國日均詞元呼叫量已突破 500 萬億。155 萬億/天大約相當於這個數字的 31%。兩個數字的口徑和統計時點都不完全可比（單叢集 tokens vs 全國詞元呼叫量；前者 2026-10，后者 2026-06），這裡只作規模參照，不作市場份額結論。

DeepSeek 這次同時開源了 DeepInfer（Apache 2.0），這套排程和快取最佳化可以被更多團隊複用；框架開源降低了復現門檻，但沒有消除經營門檻：模型權重、負載品質和運營能力仍然要自己解決。

## 七、口徑、假設與限制

- 155 萬億 tokens/天、96% 快取命中、38 美元/卡時均來自 DeepSeek 官方披露，這篇文章直接採用。
- 38 美元是收入，不是利潤。93–96% 是單卡層面的運營利潤率，只扣折舊和電費，不含銷售、研发、管理等費用，也不是公司淨利潤。
- 3–4 萬美元/卡的全棧 capex、谷價電、4 年/2 年/1 年折舊都是這裡的估算；真實 capex、電價、利用率和融資成本會改變結果。
- 牌價按官方英文價格頁（2026-10-20）的 USD 谷價：`deepseek-flash` / V4.1-Flash-1017 的 cache hit $0.003/M、miss $0.15/M、output $0.60/M；高峰時段翻倍。若後續調價，$48/$30 和 97% 的實現率要按比例重算。
- 2,370 是有效卡數。官方說機器預留了冗餘，實際部署卡數可能更多；叢集收入只能作量級參考。
- 500 萬億是媒體口徑。該數字來自公開報道，統計時點為 2026 年 6 月；155 萬億是 2026-10 的單叢集數字，兩者統計時點不同，比較只作規模參照。
- 不構成投資建議。
