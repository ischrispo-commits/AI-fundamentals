# 《Token Factory：AI 推理的成本革命》圖文講解

![封面：Token Factory：AI 推理的成本革命](img/cover.jpg)

## 寫在前面：一場關於"AI 成本"的分享

先做一個交代：這篇圖文源於一個經常被問到的問題：大模型價格跌成這樣，做算力、做推理的人還有沒有活路？

帶著這個問題，我整理了一次分享，嘗試回答三件事：**Token Factory 是不是一個好生意？怎麼才能賺錢？AI Infra 有哪些事情要做？** 下面的每一頁，都是這次分享的現場內容。

在展開之前，先把核心觀察放在最前面，方便你帶著框架看圖：

1. **AI 已經"白菜化"了**——開源生態日益成熟、呼叫價格快速走低，token 正成為 AI 服務中可計量、可定價、可交易的基礎單位。
2. **資料中心的角色正在升級**——從"算力房東"變成"產品製造商"，真正的 KPI 不再是賣出多少 GPU 小時，而是單位電力產出多少 token、對外承諾的服務品質能否穩定兌現。
3. **這門生意的關鍵只有兩件事**——一是把產能做上去：透過模型稀疏化、快取壓縮、PD 分離、投機解碼等系統工程手段，提升單卡吞吐與整體利用率；二是讓 token 更值錢：單純售賣低價 token 難以盈利，把行業 know-how 封裝成方案、讓客戶為"結果"付費，才是可持續的路徑。

## 一、開場：AI 的白菜化（頁 01–02）

![頁 01：有用性前提——"有沒有用"已不是問題](img/01.jpg)

分享從一個"反常識"的前提開始：**"有沒有用"已經不是問題了。** 四個事實支撐這句話——規模上，每月最大的開源釋出已達 754B–2.78T 參數，小米、螞蟻、美團相繼跨過 1T 線；授權上，700B–1.65T 的大模型以最寬鬆的 MIT 協議開源；生態上，HF Hub 託管著 296 萬個模型，其中 Qwen 衍生模型每天新增約 200 個；實證上，前沿閉源模型拒絕分析的攻擊程式碼，由量化開源模型 GLM-5.2 完成——開源連"閉源不敢幹的活"都能干。

![頁 02：價格的剪刀差——AI 正在經歷"電力革命"](img/02.jpg)

既然有用，剩下的問題就是價格。這一頁的兩個箭頭，是我認為理解當下 AI 產業最重要的兩個數字：**單價往下、用量往上**。每百萬 token 的輸出單價，三年大約跌了 140 倍——讓模型"輸出"一部 75 萬字小說體量的文字，三年前要 400 多元，現在約 3 元；而中國日均 token 消耗兩年增長了約 1400 倍，相當於每天寫出 1.37 億本《紅樓夢》。

這個"剪刀差"像極了 140 多年前的電力革命：愛迪生珍珠街電站送出的第一度電，按通脹折算相當於今天的 8 美元；今天美國一度電只要 20 美分左右。實際電價降了幾十倍，電力產業的總產值反而比蒸汽時代大了幾個數量級。

## 二、一座 Token 工廠：從"算力房東"到"產品製造商"（頁 03–06）

![頁 03：資料中心不再是一台計算機，它是工廠——產出 Token](img/03.jpg)

黃仁勳在 GTC 上給過一句話："資料中心不再是一台計算機，它是一個工廠——給工廠注入能量，產出的產品叫 Token。"這個比喻是我整場分享的地基。2022 年他談"資料進、智能出"；2025 年升級為"注入能量，產出 Token"；2026 年干脆宣布了"推理經濟"，新 KPI 只有一個：**Tokens/Watt——每瓦 token 產出**。誰能在單位電力裡產出更多 token，誰的成本就更低。

![頁 04：Token 是 AI 的"度"——可計量、可定價、可交易](img/04.jpg)

為什麼 token 能當"產品"來賣？因為它同時具備三重身份：**資訊單位、算力消耗單位、商業計費單位**。可計量（token 數精確可數）、可定價（按能力分層價格表）、可交易（按量計費、套餐化）——先有計量單位，後有產業。2026 年 3 月，全國科學技術名詞審定委員會與國家資料局正式將 Token 的中文標準命名確立為「詞元」，業界稱之為智力服務的"千瓦時時刻"。Token 之於 AI，等於"度"之於電力、"位元組"之於流量。

![頁 05：看 Token 工廠的三把尺子：規模、模式、產業鏈](img/05.jpg)

看 Token 工廠，我習慣用三把尺子去量。**規模尺**問"這家廠多大"：個人工作室 → 企業/主權級 → Gigascale（1GW、數百億美元）；**模式尺**問"它靠什麼賺錢"：聚合平台賺渠道費，垂類 Token 賺 Know-how 溢價；**產業鏈尺**問"它站在價值鏈哪一段"：目前算力運營方拿到 60–70% 的分成，利潤重心離"電與卡"越近越高——這個格局後面會講，它正在鬆動。

![頁 06：從賣時間到賣產出——利用率 80% 對 30%，回本 2 年對 5 年](img/06.jpg)

這一頁是全文的第一個關鍵區分：**算力房東 vs 產品製造商**。傳統智算中心賣 GPU 小時——利用率 30–50%、毛利率 20–30%、回本 3–5 年；Token 工廠賣產出——利用率 80%+、毛利率 40–50%、回本約 2 年。同樣是那張卡，客戶買的從"時間"變成"產出"，商業模式一變，賬本全變。

## 三、先看賬本與承諾，再談理想（頁 07–09）

![頁 07：Token 工廠的賬——收入靠吞吐 × 單價，成本大頭是折舊](img/07.jpg)

"回本 2 年、毛利率 40–50%"聽起來很美，但那是別人算好的結果。把賬本開啟看一遍（以下數字口徑以公開白皮書為準），結構是這樣的：

- **收入** = 年產出 × 單價；年產出 = 卡數 × 單卡吞吐 × 時間 × 利用率。四個乘數里，卡數和時間是錢能解決的，吞吐和單價才是本事。
- **成本**（以 TokenFactory 白皮書 128 節點 H20 叢集為例）：折舊 60%、電費 8%、網路 10%、人力頻寬 10%、軟體 10%。一個反直覺的事實：**折舊是大頭，電費是個零頭**——AI 工廠不吃電，吃折舊。

所以這門生意的命脈只有兩個數：**① 提升單卡吞吐和利用率；② 提升 Token 單價**（頁面上畫了個哭臉，因為單價在價格戰裡是最難提的那個）。這也是全文的主線——接下來的篇幅講第一個數怎麼被技術革命掉，最後回答第二個數怎麼提。

![頁 08：可售賣產能不是機器極限能力，是符合 SLO 的產量](img/08.jpg)

第二個數之前，先回答一個更"運營"的問題：**一台機器到底能賣多少 token？** 我自己在這件事上踩過坑，結論是：原始吞吐是"假產能"——不顧體驗硬灌負載，刷出的是流失中的使用者。真正可售賣的是 **Goodput**：成功且體驗達標的請求產出的 token。所以產能必須配一張承諾表：TTFT 按請求長度分檔、ITL P99 小於 100ms、TPOT 作為跟蹤項、成功率 ≥ 99.95%、達標率 ≥ 99%（示例量級，按業務調整）。**對外賣承諾（P99），對內考核數字**——承諾與產能是一枚硬幣的兩面：只報產能、不擔承諾，是自欺欺人；只許承諾、不練產能，是賠本買賣。

![頁 09：價格戰打到現在：真實玩家還在虧](img/09.jpg)

賬本和承諾都看明白了，再看看市場現狀，冷靜一下。官方目錄價裡，Qwen3.8-Flash 輸入 1 元 / 輸出 3 元每百萬 token，GLM-5.3-Flash 輸出 2.8 元更低；真實玩家財報裡，賣 token 的矽基流動 2025 年毛利率 −24%（賣 1 元虧 0.24 元），賣算力租賃的 CoreWeave 毛利率 66% 仍淨虧 6.26 億美元——折舊加利息吃光毛利。價格這麼低、玩家還在虧，**憑什麼還有人建、還有人投？** 這一頁留下的懸念，是全文的轉折點。

## 四、成本革命：把產能做上去的系統工程（頁 10–18）

懸念的答案在下一頁：不是市場瘋了，而是有人把成本革命到了市場價以下。理解這場革命，先理解一次生成到底在幹什麼。

![頁 10：一次生成 = 讀題存檔 + 逐字讀算；token 成本 = 算 + 存 + 傳](img/10.jpg)

一次生成分兩步：**讀題（prefill）**——把整個問題讀完、算完，把"理解"存進顯存，這份存檔叫 KV Cache，隨對話長度線性增長；**逐字（decode）**——每生成一個字，都要把存檔和權重重新讀一遍再做一次新計算。由此推出 token 成本的三個維度：參數越來越多要省**算**、上下文越來越長要省**存**、模型大到必須拆卡要省**傳**——三維都能"少做"，最終都以能量計價。

![頁 11：推理最佳化技術地圖：每一類都在"少做"](img/11.jpg)

如果把業界這幾年的推理最佳化擺成一張地圖，會發現**每一類技術都在做同一件事："少做"**。省算靠模型架構（MoE 稀疏激活、DSA 稀疏注意力、Engram 條件記憶、MTP 多 token 預測）；省存靠記憶壓縮（MLA、4-bit 量化、PagedAttention、字首快取、KV Offloading）；省傳靠拓撲與分離（專家本地化、PD 分離、拓撲感知排程）；省時靠引擎排程（連續批處理、投機解碼、動態批處理）。沒有一招鮮——每代技術各壓一維，合起來才是單價跌 140 倍的原因。

![頁 12：DeepSeek V4-Pro：每 token 只喚醒 3% 的"腦細胞"](img/12.jpg)

先看算力維。大模型動輒上萬億參數，如果每個 token 都過一遍全部參數，成本線性爆炸。MoE 的回答是：**讓模型自己少幹活**。DeepSeek V4-Pro 有 1.6 萬億參數，每生成一個 token 只激活 490 億，喚醒率 3.06%——打個比方：1600 位醫生會診，每次只叫醒 49 位。配合 DSA（128K 上下文只選 2048 個細讀）和 Engram（查表替代深層理解），模型"變大"和"變貴"第一次脫鉤了。

![頁 13：記憶壓成摘要存檔——KV 省 93%，1M 上下文 250GB → 5GB](img/13.jpg)

再看儲存維的架構層。KV Cache 隨上下文線性膨脹，1M 上下文用標準 BF16 要 250GB 顯存——一張 H200 都裝不下。DeepSeek 的 MLA 把 KV 壓進 512 維潛空間，同樣的 1M 上下文只要約 5GB，省 93%（"記憶壓成摘要存檔，用的時候再展開"）；激活的專家權重再壓成 4-bit，讀取量從 26GB 降到 6.5GB。decode 是讀權重的頻寬遊戲，讀得越少跑得越快。

![頁 14：顯存版虛擬記憶體 + 命中快取邊際成本趨零——降價 99% 仍收支平衡](img/14.jpg)

儲存維的系統層同樣重要。PagedAttention 是顯存版的作業系統虛擬記憶體——KV 切塊、按需放格，顯存利用率從 20–40% 提到 90%+；字首快取命中率 93%+，命中即免掉 prefill 重算、邊際成本趨零。小米全鏈路最佳化後 API 最高降價 99% 仍維持收支平衡——"省記憶"直接變成"敢降價"。

![頁 15：模型拆到幾個辦公室，跨辦公室溝通慢且貴](img/15.jpg)

當模型大到必須拆卡，通訊成為新瓶頸。畫面感最強的一個比喻：把團隊拆到幾個辦公室，專家/層/KV 各據一方，跨辦公室的每次溝通都慢且貴。MoE 的 all-to-all、TP 的 all-reduce、KV 搬運都在燒通訊。這裡有"通訊稅"：單節點 NVLink 頻寬約等於 HBM 的 1/9，大部分可隱藏；跨節點 IB 只有約 1/160，完全無法隱藏、產能被拖死。對策是專家本地化、**PD 分離**（讀題吃算力、生成吃頻寬，拆開跑互不拖累）與拓撲感知排程——騰訊太極 16×H20 實測 15,800 tok/s，端到端提升 30–40%。時間維上，連續批處理把利用率從 30% 提到 70–80%——同樣的卡，排程不同，產出差幾倍。

![頁 16：1GW 的工廠永遠不會變成 2GW：只有提升 Tokens/Watt 一條路](img/16.jpg)

算、存、傳都能"少做"，但有一個物理地板繞不開：供電。1GW 的工廠永遠不會變成 2GW，功率是物理上限——黃仁勳說，值錢的不是算力，是"每度電的智商"。硬體代際就是物理地板的抬升：同一個 1GW 資料中心，兩年 token 生成速率提升 350 倍（廠商口徑；SemiAnalysis 獨立實測約 50 倍，方向一致，即便打一折也快過摩爾定律同期 20 倍）；GB300 的每瓦 token 比 Hopper 系高 35–50 倍，下一代 Vera Rubin 官方口徑是成本降至 Blackwell 的 1/10。折舊可攤薄，電力攤不薄——這就是為什麼"每瓦產出"會成為工廠的頭號 KPI。

![頁 17：單價跌 140 倍——輸出/輸入價差 1:8](img/17.jpg)

技術革命的賬本結果，是一條價格瀑布：GPT-4（$60，2023-03）→ GPT-4o mini（$0.6）→ DeepSeek R1（$2.19）→ Qwen3.8-Flash（$0.43，2026-08），三年 140 倍。注意價格結構也在變：輸出是序列自迴歸、輸入可並行，輸出/輸入價差從 GPT-3.5 時代的 1:1 拉大到 GPT-5 時代的 1:8。模型還在變聰明、token 用得越來越少——真實任務的花費，降得比單價還要狠。就在 2026 年 8 月 26 日，智譜與阿里同日雙發 Flash 模型，GLM-5.3-Flash 同級智力 1/40 的價格（廠商口徑）——價格瀑布延伸到了"昨天"。

![頁 18：價格還在跌：全市場平均支付價跌破 1 美元](img/18.jpg)

不只是個別模型降價，市場整體也在降。Silicon Data LLM Token 支出指數（把全市場真實呼叫按用量加權）顯示：平均每百萬 token 的實際成交價已跌到 0.97 美元——釋出以來新低，較夏季峰值腰斬。所有人的平均支付價都跌破 1 美元了，價格戰仍在繼續。

## 五、更大的盤子，與更值錢的 token（頁 19–23）

![頁 19：單價跌了 140 倍——這個行業的總盤子，是漲了還是跌了？](img/19.jpg)

價格跌了 140 倍，用量漲了 1400 倍——那麼問題來了：**這個行業的總盤子，是漲了還是跌了？** 這一頁我在現場沒有給答案，停了幾秒讓觀眾先猜。經濟學 150 年前就預言過這件事：傑文斯悖論——煤便宜了，用量多了，總開支反而漲。

![頁 20：降價 80% → 呼叫量 ×14、收入 +34%；消耗主力正從人變成 Agent](img/20.jpg)

資料揭曉：OpenAI Luna 降價 80%，兩週呼叫量 ×14、收入 +34%；Google 月 token 處理量從 9.7 萬億漲到 1300 萬億（約 134 倍）；中國日均兩年 ×1400。更深遠的變化在需求結構裡：**消耗主力正從"人"變成"機器"**——Agent 幹一件事要呼叫模型 10–20 次，token 耗用是普通對話的 5–30 倍，2026–2028 是大規模部署的關鍵拐點。真正可怕的訊號從來不是"單 token 價格歸零"，而是"價格跌但用量停滯"——目前沒有發生。

![頁 21：從"誰的 GPU 多"到"誰的 token 值錢"](img/21.jpg)

盤子變大的同時，競爭維度在遷移：從"誰的 GPU 多"到"誰的 token 值錢"。競爭分三層——第一層效率競爭，比每瓦 token；第二層價值分層，token 已經按 $0 / $3–6 / $45 / $150 分成四檔；第三層生態卡位，聚合平台、Token 運營商、行業方案。價值正在從 token 本身，上移到 Agent、工作流與行業方案。

![頁 22：機會不在更便宜的 token，在更值錢的 token](img/22.jpg)

這頁是整場分享的落點，也是回答"怎麼才能賺錢"的答案：**機會不在更便宜的 token，在更值錢的 token**。最有說服力的證據來自同一家公司的兩個數字——矽基流動的公有云服務（賣通用 token 走量）毛利率 **−119%**，代金券補貼換增長，賣 1 元虧 1.19 元；而它的本地部署行業方案毛利率 **+82.5%**，金融、能源、政務客戶為方案付費。同樣的卡，賣法不同，天壤之別。讓 token 更值錢有兩條路：**一是生產垂類 token**，把行業 know-how 封裝進 token 與方案，賣溢價、不卷價格；**二是在應用層消耗**，做 Agent、工作流、行業方案——價值在結果，不在 token 本身。

![頁 23：問題從來不是 token 貴不貴，而是你的 token 值不值錢](img/23.jpg)

珍珠街電站送出的第一度電點亮了幾條街，140 多年后，電成了文明的基礎設施，實際電價降了幾十倍，電力產業的總產值遠超所有人的想象。Token 正在走同樣的路——價格終將趨近於零，總產值可能超過今天所有軟體產業的總和。所以問題從來不是"token 貴不貴"，而是**你的 token 產出效率高不高，你的 token 值不值錢**。

## 現場互動：國產算力與英偉達的真實差距

分享之後最熱烈的討論，集中在**國產算力卡與英偉達的真實差距**上。到場的多位從業者參與了坦誠的交流，我的觀察分三層：

1. **差距首先來自硬體設計本身**。單卡算力、顯存頻寬、互聯能力上，國產卡與國際最先進產品仍有代際差，這不是靠軟體能完全抹平的。
2. **差距同樣來自算子庫與軟體生態的成熟度**。CUDA 生態二十年積累的算子庫、除錯工具與社群沉澱，讓"同樣的模型跑出同樣好的效能"需要付出大量適配成本——硬件是"能跑"，軟體生態決定"跑得好、跑得省"。
3. **軟硬體的深度協同最佳化，仍是國產算力繞不開的長期課題**。好消息是，推理側的工作負載比訓練側更規律，這給國產算力在推理場景提供了追趕視窗——正如這次分享反覆強調的：推理最佳化的本質是系統工程，在既定硬件上把每一瓦的 token 產出榨出來，這條路對國產晶片同樣適用。
